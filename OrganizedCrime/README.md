# Организованная преступность

Раздел предназначен для материалов об организованных преступных группах и транснациональных криминально-финансовых сетях. Для каждой крупной группировки создаётся отдельный каталог.

Внутри каталога могут размещаться обзорная история группы, хронология, персоналии, география деятельности, связанные компании и судебные дела. Утверждения правоохранительных органов, установленные судом факты и журналистские версии должны быть явно отделены друг от друга.
