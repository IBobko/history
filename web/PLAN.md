# Сайт исторического архива

Первая версия: Next.js, чтение Russia, USA и Common, поиск по всему архиву,
фильтры, лента и сопоставление категорий по общей григорианской хронологии.
Исходные Markdown-файлы не изменяются. Старые блоки без заголовков событий
показываются целиком. Нераспознанные даты и отклонения фиксируются в отчёте.

## Реализация

1. Модель события и отдельный адаптер Markdown. Оригинальная дата сохраняется;
   дата для сопоставления хранится отдельно с точностью и календарём.
2. Каталог годов, полнотекстовый поиск, фильтрация категорий и периода.
3. Лента, параллельные линии по месяцам, отдельная страница события и исходник.
4. Проверки импорта, типов, производственной сборки и интерфейса.
5. Docker Compose на 91.99.238.7, проксирование todo100.ru через 155.212.175.209,
   HTTPS и проверка существующих сайтов после добавления конфигурации.

## Дальнейшее развитие

Интерфейс обращается к EventRepository, а не к файловой системе. Следующий
адаптер может читать PostgreSQL. Для редактора понадобятся аутентификация,
история изменений и решение о владельце актуальной версии события.

Идентификаторы первого импорта производятся из категории, исходной даты,
заголовка (либо начала старой записи). При переходе на редактирование они
переносятся в постоянный реестр; изменение этих исходных полей до этого
изменяет ID. Двусторонняя синхронизация с Markdown в первую версию не входит.

Markdown остаётся авторитетным источником. Новые события добавляются через
tools/timeline.py. Изменения архива видны после обновления файлов на сервере;
повторная сборка образа для изменения текста не требуется.
